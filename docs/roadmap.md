# 路线与未做项

## 已完成

- ✅ 四层链路打通：模型 → 桥 → 控制器 → 反馈
- ✅ 9 节 32 项回归断言全 PASS
- ✅ ONNX 导出（ORT CUDA 211 ms，数值等价 1.3e-06）

## 下一步（按性价比）

| 顺序 | 做什么 | 耗时 | 补什么 |
|---|---|---|---|
| 1 | ~~fp16 导出对比~~ **已做，结论负面** | 已完成 | 体积减半到 789 MB，但数值崩（相对误差 111%）、延迟只快 1.04× —— 见 [ONNX 实验](/onnx) |
| 2 | **Gazebo 最小场景** | 1–2 天 | 补动力学与碰撞（当前 mock 只镜像命令） |
| 3 | **TensorRT engine** | 半天（含踩坑） | **唯一有意义的加速路线**：层融合能把 11,640 节点压成几十个 kernel |

## 明确没做（别对外说过头）

| 没做 | 后果 |
|---|---|
| 无真机 | 驱动层限幅、真实摩擦/回差 未验证 |
| 无相机 | 模型输入是合成图像，输出不代表真实语义 |
| 未接 Gazebo | 没有动力学与碰撞，撞墙不会停 |
| `/estop` 未上真控制器 | 只在 mock 上验过全零锁死 |
| fp16 / TRT 未跑 | 加速只做到 ORT fp32 |
| 未测吞吐 | 只有单帧延迟，没有多路并发数据 |

## 一句话总结

> 训练侧成本正在暴跌（世界模型把策略训练从 21000 GPU-h 压到 3 GPU-h），
> 但**把策略落到硬件上的工程成本一点没降** —— 这部分仍然是手写、可测、要证据的活。
